# Model card

## Scope

Small decoder-only language models trained from random initialization on Tiny
Shakespeare. Intended for experiments with language modeling, tokenization, and
training infrastructure. They are not instruction-tuned assistants or general
question-answering models.

The implementation follows GPT-2's architecture at a much smaller scale. It uses
learned absolute position embeddings, pre-normalized transformer blocks, GELU MLPs,
and tied input/output weights. There is no KV cache or distributed training.

| Property | Character | Byte BPE |
|---|---:|---:|
| Layers / heads / width | 4 / 4 / 128 | 4 / 4 / 128 |
| Context | 128 tokens | 128 tokens |
| Vocabulary | 65 | 512 |
| Parameters | 818,048 | 875,264 |

## Data and evaluation

Tiny Shakespeare contains 1,115,394 ASCII bytes in the verified source file.
Contiguous 90/5/5 splits are made before fitting the tokenizer; see
[data provenance](../data/README.md). The split is not deduplicated or grouped by play.

Reference runs use 2,500 AdamW updates, batch size 16, seed 1337, and CPU float32.
Validation selects checkpoints; full-split evaluation scores all targets once with
context reset every 128 tokens. [Results](RESULTS.md) include statistical baselines,
perplexity, and bits per byte. The source repository includes logs and configurations;
weights are local training outputs and are not distributed here.

## Limitations

- Outputs can be incoherent, repetitive, or grammatically incorrect. The training
  corpus contains historical language and biases.
- One seed on a narrow corpus does not establish broad language ability.
- Tokenizer experiments differ in parameter count, byte context, and text exposure.
- Character prompts must use the training alphabet. BPE accepts arbitrary UTF-8,
  but generated byte sequences may require replacement characters when decoded.
- Exact checkpoint recovery is tested in a controlled CPU setting. Different
  hardware, software versions, or numerical backends may change results.
- The CUDA preset is provided for experiments; no GPU results are reported.
